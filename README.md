# cli-player
A lightweight terminal MP3 player built with Python, curses, and VLC. Folders become playlists, with shuffle, loop, seek, and volume controls.

(this was made for fun)

## Controls

| Key | Action |
|-----|--------|
| `Space` | Play / pause |
| `↑` / `↓` | Volume up / down |
| `←` / `→` | Seek -5s / +5s |
| `n` / `p` | Next / previous song |
| `]` / `[` | Next / previous playlist |
| `l` | Cycle loop mode (off, song, playlist) |
| `r` | Toggle shuffle |
| `q` | Quit |
